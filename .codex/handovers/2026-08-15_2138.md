## Pitfalls and Warnings

- 隔離実行ユーザーとWindowsユーザーで`.git`所有者が異なるため、Gitが`detected dubious ownership`で停止する場合がある。グローバル設定は変更せず、必要なコマンドだけ次の形式にする:

```powershell

```

- `python`はPATHにない。標準ライブラリスクリプトは`.venv\Scripts\python.exe`を使うか、プロジェクト内で`uv run python ...`を使う。
- sandbox内のオンライン`uv run --extra test pytest -q`はPyPIへのソケット接続が`os error 10013`で失敗した。依存物がキャッシュ済みなら`uv run --offline --extra test pytest -q`で検証できる。
- `python/boltzpm2/data/Ar.txt`と`Ar_star.txt`は検証用近似データであり、本計算には信頼できるLXCatデータを指定する。
- 低E/Nでは物理的緩和時間が長いため、Rust化だけでは必要ステップ数そのものは減らない。収束加速を実装する場合は互換ソルバーと別オプションにし、物理量を再検証する。
- `parallel=True`を既定化しない。代表メッシュで遅くなることが確認済み。
- `dist/`は`.gitignore`対象。ローカル成果物を再利用する前にバージョンとSHAを確認し、公開時はできればCIでクリーンビルドする。
